Sources

Cette page rassemble les sources, inspirations et références utilisées pendant la création du site. Elle distingue les sources techniques, les inspirations visuelles, les images, les vidéos et les outils de validation.

Inspirations visuelles

Couleurs du Sénégal

Le choix des couleurs vert, jaune et rouge s’inspire de l’univers visuel du Sénégal et du football sénégalais. Ces couleurs ont été adoucies pour obtenir une charte plus sobre et adaptée à une vitrine professionnelle.

Wikimedia Commons - Drapeau du Sénégal

Maillot officiel du Sénégal

Les maillots officiels du Sénégal ont servi de référence d’ambiance pour relier la palette graphique à une inspiration football.

PUMA - Sénégal Football

Minimalisme

La démarche graphique suit une logique minimaliste : limiter les éléments inutiles, réduire le bruit visuel et mettre en avant les informations importantes.

Nielsen Norman Group - Aesthetic and Minimalist Design

Sources des images

Les images utilisées dans le site sont soit des captures personnelles, soit des images externes utilisées comme illustrations. Les images externes sont citées dans les légendes des pages concernées et regroupées ici.

  • Captures personnelles : images des projets présentés dans la page Projets.
  • Wikimedia Commons : drapeau du Sénégal, utilisé comme référence visuelle pour la palette.
  • Pexels : images d’illustration utilisées pour certains blocs de la page Démarche.
  • Unsplash : images d’illustration éventuelles utilisées pour représenter la conception, le travail web ou l’hébergement.

Source vidéo

Une vidéo YouTube est intégrée dans la page Démarche pour illustrer la réflexion autour du minimalisme et de la composition visuelle.

  • Vidéo YouTube intégrée dans la page Démarche, utilisée comme référence complémentaire sur le minimalisme.

Sources liées à l’hébergement

Le site est pensé comme une base pouvant être hébergée plus tard avec d’autres projets. Les sources ci-dessous ont été consultées pour comparer des pistes d’hébergement compatibles avec PHP.

o2switch

Hébergeur envisagé pour la mise en ligne future du site et d’autres projets. Cette piste est liée à une expérience précédente avec cet hébergeur.

o2switch - Hébergement

Hostinger

Hébergeur envisagé comme solution possible selon le rapport entre le prix annuel, les fonctionnalités disponibles et la compatibilité PHP.

Hostinger - Hébergement PHP

Outils et validation

  • Visual Studio Code / VSCodium : édition des fichiers HTML et CSS.
  • Brave : navigateur utilisé pour tester l’affichage des pages.
  • Validateur W3C : outil prévu pour vérifier la validité du code HTML.
  • Codeberg : plateforme pour publier le dépôt du code source.

Contenu personnel

Les textes de présentation, les descriptions de profil, les compétences et les projets sont rédigés pour ce site. Les captures liées aux projets sont des captures personnelles ou des illustrations liées au travail réalisé.
